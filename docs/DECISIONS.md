## D. Данные и качество

| # | Решение | Статус |
|---|---|---|
| D1 | Номенклатура обновляется из Ozon **полностью автоматически, но с валидацией**: у новых карточек нет сопоставления с 1С → **помечать, а не молча считать**. | Реализовано: колонка Q + «Проблемы данных» |
| D2 | **Вопрос №19:** автоподстановку скидки «оставить как есть», **но объяснять**, значение поставлено автоматически или вручную. | Реализовано: обоснование в C14, лог |
| D3 | **Вопрос №20: уведомления о новых карточках НЕ НУЖНЫ.** Достаточно пометки в колонке Q и листа «Проблемы данных». | ❌ **Не предлагать почту/алерты повторно** |
| D4 | **Вопрос №21:** отсрочку выплаты 84 дня **оставляем**. Действий не нужно; при смене срока — просто перемерить кнопкой. | Закрыт |
| D5 | Аудит 18 строк (12.10.2026): `standard_fee / (seller_price_per_instance × quantity)` совпадает с `commission_ratio`; отдельная скидка 1,5 п.п. этими данными не подтверждена. B14 этим аудитом не калибровать и оставить без изменений. | Формула исправляется; отдельная скидка требует независимого подтверждения |
| D6 | **Подписка Premium Plus активна** — использовать её возможности: отчёт о реализации, `delivered_units`, `returns`, `cancellations`. | Реализовано в v0.7 |
| D7 | Витринную цену покупателя пробовали — **недоступна**. | Закрыто, не искать повторно |
| D8 | **Согласованные правила расчёта Э2/Э3 (13.10.2026):** (1) комиссия: сначала `Комиссия факт!J`, иначе `Факт Ozon!W/X`, B14 не менять; (2) выкуп из `Продажи!M` в диапазоне `0–100%`, пустое/`<0%`/`>100%` заменять на `Параметры!B8` с предупреждением, `0%` принимать с блокировкой цены; (3) возвратный тариф = `тариф возврата × (1 − выкуп) / выкуп`; (4) целевая цена по проверенной формуле до налогов, НДС и налог на прибыль отдельно; (5) каскад наценки `SKU → категория (Номенклатура!P) → общая (Параметры!B10/B9)`; (6) округление цен вверх по шагу `Параметры!B11`; (7) ограничения акций по каждой строке «Акции» (`наш пол ≤ лимит Ozon`), без отправки цен в Ozon. | Реализовано в `core/unit-economics.js` и `appsscript/05_Calculation.gs` |

## G. Отклонённые и мёртвые направления

Записано, чтобы не предлагать повторно:

1. **`adv_sum_all` как источник расходов на рекламу.** Метрики не существует
   в официальной схеме (0 вхождений). Реклама — только Performance API.
2. **`/v3/finance/transaction/list`** — отключён 08.09.2026.
3. **`performance.ozon.ru`** — хост мёртв с 15.01.2025.
4. **Витринная цена покупателя через API** — `marketing_price` отключён 12.11.2025.
5. **Уведомления о новых карточках** (почта, алерты) — пользователь отказался (D3).
6. **Хранение ключей в таблице** — запрещено (C1).
7. **GitHub-токен внутри песочницы** — отклонено по правилу C1.
8. **Захардкоженная скидка к комиссии** — устаревает: изменена 28.09.2026.
9. **Замена файла модели на Drive через upload_file** — невозможна без потери
   привязанного Apps Script и `Script Properties` с ключами. Всё новое делается
   функциями из меню.
